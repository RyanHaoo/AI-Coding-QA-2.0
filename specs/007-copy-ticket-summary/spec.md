# 工单摘要复制

日期：2026-10-07。状态：实现与验证完成。

## 用户故事（P1）

质检员或管理员查看工单后，将问题交接给施工负责人。点击详情顶部“复制摘要”，得到可粘贴到项目群的文字，避免重新整理信息；发送由用户自行完成。

## 功能需求

- 摘要包含工单编号、项目、位置、问题描述、严重程度、当前状态、责任人和详情链接。
- 复制当前已保存的信息，不包含图片、全部处理记录、未保存编辑或登录信息。
- 复用详情头部和 Button 样式；复制期间避免重复点击，成功后明确提示。
- 浏览器不支持或拒绝自动复制时，提供只读摘要文本供手动复制，不阻塞详情。
- 链接仅保留 ticketId，按访问者当前角色进入对应详情容器，沿用项目权限。接收人先登录对应项目，未登录时可登录后重新打开链接。
- 不修改工单状态，不自动发消息，不新增后端依赖。

## 验收场景

1. 点击复制，粘贴文字含全部字段，值与详情一致。
2. 带筛选参数的详情复制出同源链接，链接仅含 ticketId。
3. 剪贴板失败时不提示成功，显示可选中的手动复制文本，按钮可重试。
4. 桌面和窄屏均可使用；刷新或切换工单不执行复制。

## 成功标准与范围

一次点击生成交接摘要，通过静态检查及内置浏览器验证。用户明确允许用示例数据验证，不要求 Supabase、模型及完整业务链路打通。

# UI 契约: 路由切换 Loading 遮罩

## 触发范围

- 侧栏页面导航。
- 工单列表、详情与返回入口。
- 管理员大盘指标下钻和工单中心筛选。
- 其他使用 Next.js `<Link>` 触发的根页面查询参数导航。
- 初次访问在服务端渲染超过阈值时允许复用该 fallback。
- 同源且不同于当前 URL 的普通左键链接点击必须进入 Provider pending；外链、下载、修饰键点击和当前链接必须跳过。

## 展示契约

- fallback 挂载后立即生成覆盖完整视口的固定层，层级高于现有移动菜单。
- 固定层立即拦截指针事件；可见遮罩和加载卡片延迟 150ms 淡入。
- Client Provider 触发的遮罩必须叠加在旧界面上方，并使用半透明背景保持旧内容可见。
- 加载卡片居中展示旋转图标与固定文案“页面加载中…”。
- 状态容器使用具有隐式 status 语义的 `<output>` 与 `aria-live="polite"`。
- reduced-motion 环境停止图标旋转，但不隐藏文案。

## 完成契约

- 根级 fallback 由 Next.js 自动卸载；Provider 遮罩在当前 URL key 变化后停止渲染。
- 卸载后恢复页面交互，不遗留遮罩、计时器或客户端状态。
- 目标 URL、查询参数、筛选上下文和页面数据不因遮罩而改变。

## 排除项

- Server Action 表单提交。
- 图片上传。
- 智能助手生成回复。
- 独立的逐链接 pending 图标或全局客户端路由状态。

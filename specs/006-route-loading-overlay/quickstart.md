# Quickstart: 路由切换 Loading 遮罩

## 前置条件

1. 保持现有 `.env.local` 中的 Supabase 配置可用。
2. 使用仓库测试账号登录，以便进入工单和管理员页面。
3. 仅使用 Codex 内置浏览器进行真实浏览器验收。

## 静态验证

```powershell
npm run check
npm run build
```

预期：Biome 格式化、lint、TypeScript 类型检查和 Next.js 生产构建全部通过。

## 本地运行

```powershell
npm run dev
```

开发服务必须以可终止的持久会话运行，验收完成后关闭。

## 验收路径

### 1. 桌面端慢导航

- 登录后进入任一业务页面。
- 在内置浏览器中启用受限网络，依次点击侧栏、工单详情、返回列表、筛选和排序入口。
- 预期：等待达到约 150ms 后出现全屏遮罩、旋转图标和“页面加载中…”；目标内容完成后遮罩自动消失。

### 2. 防止重复操作

- 在慢导航遮罩出现时连续点击页面。
- 预期：遮罩覆盖整个视口并拦截后续指针操作，不触发第二次导航。

### 3. 快速导航

- 恢复正常网络并切换已预取内容。
- 预期：150ms 内完成时不出现可感知遮罩闪屏。

### 4. 移动端

- 将视口调整为移动尺寸，打开侧栏后点击导航。
- 预期：遮罩层级高于移动菜单、顶部栏和主内容，完整覆盖视口。

### 5. 减少动态效果

- 模拟 `prefers-reduced-motion: reduce` 后触发慢导航。
- 预期：加载文案和遮罩仍可见，图标不旋转。

### 6. 回归确认

- 检查导航完成后的 URL、查询参数、筛选上下文和页面数据。
- 预期：均与导航目标一致；表单、图片上传和助手回复的既有等待态不变。
